### Math object

            eg:

            it is used to find minimum number

            eg:
                    Math.min(3,5,8)     //3

        3.Math.sqrt()

            it is used to find the square root of any number

            eg:
                    Math.sqrt(9)     //3

        4.Math.abs()

            it is used to provide the positive value

            eg:
                    Math.abs(-34)     //34

        
        5.Math.floor()

            it is used to provide floor value of the number.

            eg:
                    Math.floor(5.9)     //5


        6.Math.ceil()

            it is used to provide the next value of the number

            eg:
                    Math.ceil(8.02)     //9


        7.Math.round()

            it is used to proovide the roundoff value of the number

            if the decimal value is .5 or more than that it will give the next value.


            eg:
                    Math.round(3.5)     //4
                    Math.round(3.4)     //3

        8.Math.pow()

            it is used to know the power any number 
            it takes two parameters base and the power

            eg:
                    Math.pow(3,2)     //9

            it is used to generate the random numbers between 0 to 1
